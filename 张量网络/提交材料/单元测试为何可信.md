# 单元测试为何可信，以及它不能证明什么

> 本笔记说明当前测试的判断依据。结论是：测试能检查最小实验的关键约定和已知错误，不能证明整个系统“绝对正确”。关联文档：[[完整设计]]、[[实验指标与评估规则]]。

## 测试对象和判定标准

候选函数 `find_path(inputs, output, sizes, seed=0)` 返回动态位置表示的两两收缩路径。评估器先检查路径，再用固定版本的 cotengra 计算给定路径的标量运算代价。**测试里的预期值不能都由被测函数自己算出**，否则两处代码犯同一个错误也可能通过。因此当前采用三类核对：手算的已知值、独立写出的简单计数、以及接口与错误行为的端到端检查。

## 12 项自动测试分别检查什么

### 固定实例：1 项

`test_fixed_instances_match_generators_and_network_rules` 用保存的参数和种子重生成全部 6 个 JSON 实例，并逐字段比较。它还检查格点的张量数和边数、量子电路的开放指标数、每个内部指标出现两次、开放指标出现一次，以及当前实例的指标维度均为 2。

**为何有意义**：能发现固定文件被改动、生成参数写错或依赖版本造成的数据漂移。**边界**：重生成仍依赖同一个生成库，不能独立证明该库的物理语义正确；它只覆盖现有 6 例。

### 路径与代价：4 项

| 测试 | 独立判断依据 | 能发现的错误 |
| --- | --- | --- |
| `test_known_chain` | 三张量链两条路径的手算代价分别为 64、90，峰值为 20 | 收缩代价或最大张量计算的明显错误 |
| `test_all_three_tensor_first_pairs` | 测试文件中的 `direct_cost` 逐步计算指标并求维度乘积，再与 cotengra 结果比较 | 不同首步路径上的计数不一致 |
| `test_reject_invalid_paths` | 手工构造缺步、重复位置、越界位置及非整数位置 | 非法路径被当成有效结果 |
| `test_baseline_repeatability` | 同一小实例上重复调用三条基线，比较路径和正代价 | 当前进程内明显的不稳定性 |

`direct_cost` 没有调用 `score_path` 或 cotengra，因此提供了另一条实现路径；但它与正式评估器仍共享同一套收缩代价定义。`test_baseline_repeatability` 只测一个实例和同一进程，不能证明跨平台、跨进程完全可复现。

### 候选执行和反馈：7 项

| 测试 | 预期结果 |
| --- | --- |
| `test_initial_evaluator` | 原始 Greedy 程序在 4 个开发实例上都有效，得分为 0 |
| `test_any_invalid_case_rejects_candidate` | 无效候选在 4 例上全失败，分数为固定的 `-10` |
| `test_candidate_exception_and_invalid_path` | 候选抛异常或返回重复位置时，评估器返回错误记录 |
| `test_runner_json_protocol` | 独立子进程接收 JSON 实例并返回可解析路径 |
| `test_candidate_timeout` | 故意延迟的候选触发短时限，记录 `timeout` |
| `test_api_probe_selects_fast_listed_model` | 模拟 API 检查选中列出的模型，并发送 `enable_thinking: false` |
| `test_failed_candidate_feedback_reaches_next_prompt` | 失败实例的具体错误被整理进下一轮反馈文字 |

这 7 项覆盖了生成代码与评估器的接口，以及失败不会被误记为改进。API 测试使用模拟对象，只检查本地调用参数；它不能证明 SiliconFlow 服务稳定或真实模型会生成正确代码。

## 超出单元测试的检查

`smoke_mock.py --feedback` 使用本机假模型跑两轮完整流程：第一轮返回错误候选，第二轮收到具体错误，再执行和计分。检查还确认 `enable_thinking: false` 进入请求、最佳分数与独立复核一致。这是集成测试，不在上述 12 项单元测试数量内。

真实 SiliconFlow 曾生成一份候选代码，但该代码错误调用 `oe.paths.greedy`，4 个开发实例均失败。这次失败说明**评估器确实拒绝了接口错误**，不说明模型或新算法已经有效。调整后的真实多轮运行仍待验证。

## 尚未得到的保证

1. **不是数学证明**：有限测试不能穷尽所有网络、路径和库版本。下一步可对更多小网络穷举路径，并加入另一套明确相同 FLOPs 约定的实现交叉核对。
2. **不是物理验证**：目前主要核对网络结构和收缩代价，没有独立计算量子态振幅来验证电路张量网络的数值语义。
3. **不是安全沙箱**：候选在限时子进程中运行，但仍能读取同一工作区。保留集没有严格隔离，不能据此声称泛化评估完全独立。
4. **不是公平性能比较**：三条基线和 Agent 候选尚未统一找路径预算；当前 6 个实例也太少，不能支持算法优劣结论。

复现命令：在 `experiment/` 目录运行 `.\.venv\Scripts\python.exe -m unittest discover -s tests -v`。测试实现见项目中的 `experiment/tests/test_experiment.py`。固定依赖版本见 `experiment/requirements.txt`。
