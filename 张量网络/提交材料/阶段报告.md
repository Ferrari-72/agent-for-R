# 最小实验阶段报告

记录截至 2026-10-21 的本机结果。实验目标是让 Agent 修改 `find_path(inputs, output, sizes, seed=0)`，为不同张量网络返回合法的两两收缩路径。

## 已实现

| 模块 | 现状 | 证据 |
| --- | --- | --- |
| 固定实例 | 4 个开发实例、2 个保留实例，覆盖格点和完整态电路 | `experiment/data/` |
| 独立评估 | 检查路径、异常和超时；用 cotengra 计算给定路径的代价与最大中间张量 | `experiment/tnlab/scoring.py`、`experiment/openevolve_evaluator.py` |
| 基线 | Greedy、Random-Greedy、模拟退火，记录逐实例结果 | `experiment/run_baselines.py`、`experiment/reports/baselines_*.json` |
| Agent 接入 | OpenEvolve 生成候选、限时执行、评分和记录；失败详情可进入下一轮提示 | `experiment/run_minimal.py`、`experiment/smoke_mock.py` |
| 复核 | 12 项单元测试通过，包含六个固定实例的重生成与结构核对；最终最佳代码另行复算开发集和保留集 | `experiment/tests/` |

开发集四例的路径代价如下。数值越小越好；这些方法的找路径预算尚未统一。

| 方法 | 格点 2×2 | 格点 2×3 | 电路 3q d1 | 电路 3q d2 |
| --- | ---: | ---: | ---: | ---: |
| Greedy | 20 | 60 | 148 | 372 |
| Random-Greedy | 20 | 52 | 144 | 364 |
| 模拟退火 | 20 | 52 | 116 | 308 |

## 真实模型运行

- `DeepSeek-V3.2` 的首次生成请求超时，没有候选代码。
- `Qwen/Qwen3.5-4B` 完成一次候选代码生成。候选向 `opt_einsum.paths.greedy` 传入不支持的 `seed` 参数，4 个开发实例均失败。OpenEvolve 保留原始 Greedy 程序；独立复核分数为 0。记录在 `experiment/results/evolve_20261022T042137Z_a44b2c/`。
- 后续 `Qwen/Qwen3.6-27B` 的短 API 检查成功，但第一轮完整生成请求两次超时，没有新候选。记录在 `experiment/results/evolve_20261022T042916Z_c341c5/`。

已修改提示，写明相关库接口；将失败原因传给下一轮；把请求设为关闭思考模式、最多 1024 个生成 token、75 秒超时且不重复请求。新的完整真实运行**尚未验证**。短请求成功不能证明完整提示能按时返回。

调整后的两轮本机模拟已通过：首轮无效候选的错误出现在第二轮提示中，`enable_thinking: false` 进入模型请求，最终报告与独立复核一致。它使用本机假模型，不能代替真实 API 结果。

## 结论与边界

评估器、基线和真实模型“生成代码 → 执行 → 判错”的链路已有证据。还没有“真实多轮产生有效改进”的证据。保留集与候选执行环境没有严格隔离；当前实例很少，不能据此判断泛化或算法优劣。单元测试能发现已覆盖的错误，不能保证评估器绝对正确。
