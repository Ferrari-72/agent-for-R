# 公开拓扑与资源工程试跑

本包检查小型 full-state 电路和开放格点的拓扑生成、有限结构比较，以及三条人工路径搜索起点的合法性、重复性和资源表现。它承接相邻的 `../teacher_review_20261027/`，后者保存三条候选的源代码和独立评分工具。本包不改变该历史包。

日期：2026-10-27。用途：`public-engineering-only`。所有生成的结构均已公开用于开发，不能再作为未见测试样本。正式研究规模的样本、历史结构语料和研究 split 均未装载或生成。

## 阅读顺序

1. `pilot_spec.json`：固定规模、数量、抽样规则和资源预算。
2. `topology.py`：仅标准库的拓扑生成与结构校验。
3. `pilot.py`：Linux 内生成、比较、候选执行和独立评分。
4. `run_pilot.py`：宿主只负责源码复制、镜像核对、Docker 调度和证据保存。
5. `pilot_notes.md` 和 `pilot_summary.json`：实际观察、结论边界及机器可读明细；以完成后的报告为准。

## 试跑设计

| 任务族 | 工程规模 | 每格数量 | 合计 |
| --- | --- | ---: | ---: |
| full-state 电路 | 4/6 比特 × 深度 2/3 | 3 | 12 |
| 开放格点 | 2×3、3×3 | 2 | 4 |

电路以每比特一个 rank-one 输入开始，按层交替设置不重叠的相邻二比特门；每个可选门由固定 SHA256 规则保留或省略，省略时不插入 identity 张量。每个已保留门增加一个 rank-four 张量和两条新线段，最终每比特一条输出。格点按行优先顺序枚举右边、下边，用同一形式的哈希规则删边，拒绝不连通图；每个顶点保留一个开放 physical index。全部维数为 2，不分配研究数值张量。

每格按 attempt 从 0 开始，最多 32 次，依次对已经接受的全部工程结构比较。重复和不连通等拒绝会消耗尝试；比较返回 `unknown` 或外部超时则停止该格并报告失败，不将它算作不相交。全部结构池在首次候选执行前确定，候选代价和运行时间不参与接收或补样。

采用镜像中已有的 `tnlab.structure_equivalence.compare_structures`，政策为 `tensor-index-incidence-v1`。每次比较最多 10,000 个搜索状态，每个 draw 的生成和全部比较共用一个 5 秒 fresh-process 截止。外部超时与核心返回 `unknown` 分别保留。该政策保留输出的**顺序位置**，允许标签重命名、输入张量重排和单张量索引重排；它不证明允许任意输出置换后的结构唯一性，也没有单独编码门类型或输入态等张量语义角色。不能据此签发正式科研去重或 unseen 资格。

每个接受结构运行 partition、tree、beam 三条候选路线，算法 seed 固定为 0，分别在两个 fresh process 执行；只有两次均成功、路径一致且评分通过，整个槽位才合格。Python 使用 `-I -B`，不声称控制 `PYTHONHASHSEED`。候选和独立评分分别有 10 秒进程截止，峰值限制为 `2**30` 个元素。峰值包含原始输入与中间张量，是符号张量体积，不等于实际数值收缩的内存占用。

独立评分同时使用 set-based 路径模拟和固定版本 cotengra，检查完整 `n−1` 步动态位置二元路径、FLOPs 和峰值元素数。索引总数不超过 18 的工程实例还运行直接整数 einsum 与按路径整数收缩的一致性检查；数值使用专门的确定性工程值，不代表量子态或酉门物理验证。其余实例只作符号复核。

## 复现

从仓库根目录运行：

```sh
python -I -B experiment/deliverables/engineering_pilot_20261027/run_pilot.py
```

本地必须已经存在固定 Linux 镜像 `sha256:ad059619f459c42aded047c343847fc4fc7fd9e025b3993b687768c9f549d5b3`，以及相邻教师包中的 `heuristics.py` 和 `validate.py`。启动器不会构建或拉取镜像，不读取项目 config、数据集或请求账本。

全部业务代码在 Linux Docker 中执行，宿主仅编排和保存元数据。容器只读挂载本轮精确源码副本，网络关闭、UID 65534、1 CPU、内存与 memory+swap 均为 2 GiB、64 PIDs。生成、候选和评分子进程串行共享此容器资源边界；这不构成针对任意不可信候选的安全沙箱，也不是每个子进程各自独占 2 GiB。宿主另有 2,400 秒总截止和超时清理。

每次调用都在 `experiment/results/engineering_pilot_<唯一标识>/` 保留 invocation、源码副本、stdout、stderr、进程退出状态及可解析的 completion。报告通过后才写入本包的 `pilot_summary.json`。镜像内置源码身份和本轮只读挂载源码分别记录 SHA256，二者不能互相替代。耗时和 RSS 随机器变化，复核重点是源码身份、抽样顺序、结构、路径、评分、槽位与失败分母。

## 结论边界

小工程实例只能支持相应规模上的生成和执行可行性。它们不能证明正式 8/12 比特开发规模、16/20 比特规模测试或 4×4/5×5 格点的资源可行性。没有运行四固定基线对照、真实模型请求、准确 tokenizer 测量、价格核算或正式研究流程；这些仍需各自的后续证据。
